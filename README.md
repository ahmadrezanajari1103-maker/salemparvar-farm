# دفتر پرورش سالم پرور

اپ آفلاین (PWA) ثبت آمار روزانه‌ی مرغداری گوشتی سالم پرور — شرکت مرغ پرور.

## قابلیت‌ها
- ثبت هوشمند متن آزاد فارسی (تلفات، حذفی، دان ورودی/توزین، وزن‌کشی، دارو، واکسن، دوره‌ی آنتی‌بیوتیک، خاموشی، دما، وعده، توضیحات) — حتی چند روز با هم
- ویرایش مستقیم هر خانه‌ی جدول
- گزارش روزانه‌ی JPG طبق فرم چاپی + علامت «ارسال شد»
- گزارش تجمیعی PDF (A5 افقی)
- ضریب تبدیل روزانه و آخر دوره، مانده‌ی انبار دان
- تا ۶ سالن، کاملاً آفلاین، داده‌ها فقط روی دستگاه کاربر

## ساختار
| مسیر | محتوا |
|---|---|
| `src/core.js` | تقویم جلالی، مدل داده، محاسبات |
| `src/parser.js` | کادر هوشمند (واژه‌نامه، تاریخ، ساعت، چندروزه) |
| `src/actions.js` | ثبت، ویرایش، حذف، دوره‌ها، تنظیمات، پشتیبان |
| `src/export.js` | فرم روزانه، PDF تجمیعی، اشتراک |
| `src/views.js` | رابط کاربری |
| `docs/` | خروجی ساخته‌شده (برای GitHub Pages) |

## ساخت و تست
```
python3 tools/build.py      # ساخت docs/index.html
node tests/run.js           # تست کادر هوشمند (۱۰۵ جمله)
python3 tests/e2e.py        # تست مرورگری (Playwright)
```

## داده‌ها
کلیدهای ذخیره‌سازی `mehr1405:v2:data` و `mehr1405:v2:settings` در نسخه‌های جدید تغییر نمی‌کنند.
برای انتقال به آدرس یا گوشی دیگر از «پشتیبان» و «بازگردانی» در تنظیمات استفاده کنید.
